# 询单结构式提取与回填

> 目标：把一份需求文档里的全部结构式图片，按文档顺序搬进固定模版的「结构式」列，
> 产出一份可直接发给客户的咨询表。**源文件只读、模版不覆盖**，产物是新文件。

## 一、先确认三件事

1. **源文件**：`.docx`（Word 需求单/询单）或 `.xlsx`（含图片的表格）。
2. **固定模版**：表头里有一列写着「结构式」（例如「结构式/产品信息」）的 xlsx。
   详细要求见 `references/template-requirements.md`。
3. **保存位置**：由用户指定；没指定就放在源文件同目录。

## 二、跑起来

```bash
node scripts/export.mjs "<源文件.docx>" "<输出目录>" "<输出文件名>" --template "<模版路径>"
```

- 模版路径优先级：`--template` > 环境变量 `TEMPLATE_XLSX` > 默认 `<USER_HOME>\Desktop\业务咨询货号申请表.xlsx`
- 输出目录 / 文件名可省略：默认落在源文件同目录，文件名 `结构式_导出_<日期>_<时分>.xlsx`
- 同名文件不覆盖，自动加序号（`名字 (2).xlsx`）

跑完会打印一行摘要，照抄给用户即可：

```
提取：  19 张图片 → 第 3~21 行（6 列「结构式/产品信息」）
输出：  D:\...\结构式_导出_20261117_0921.xlsx  (304.1KB)
```

## 三、产出规格（写清楚，免得用户来问）

| 项 | 口径 |
|---|---|
| 图片顺序 | **文档从上到下**：Word 按段落/锚点顺序，Excel 按行号顺序 |
| 起始行 | 模版表头行的下一行（数据首行） |
| 每行 | 一张图，落在「结构式」列（合并单元格内按比例缩放并居中） |
| 行数不够 | 自动扩展表格行，不截断、不丢图 |
| 模版 | 原样保留（合并单元格、行高、列宽、边框、字体），只新增图片 |
| 产物 | 新建 xlsx，文件名可指定 |

## 四、注意事项

- **纯 Node 实现**，不依赖任何第三方包；不联网，全部在本机完成。
- 源文件里的图片可能是 PNG/JPEG/GIF/BMP/EMF，脚本按扩展名自动识别。
- 模版里如果残留了「没有图片的空占位框」，写入前会被清掉，不会混进产物。
- 模版被改名或挪走时，插件侧能按内容自动找回；**命令行这条不自动找回**，请显式 `--template`。

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 「模版里找不到「结构式」列」 | 表头没写「结构式」 | 换模版，见 `references/template-requirements.md` |
| 「这个文件里没有提取到任何图片」 | 源文件里图片是外链/形状而非嵌入图片 | 让对方另存为 docx/xlsx 再试 |
| 「模版不存在」 | 路径不对 | 用 `--template` 或设 `TEMPLATE_XLSX` |
| 图片数量比预期多/少 | 文档里还有别的图（截图、印章、签名） | 打开产物核对；逐张挑选需要另用工作台版（见插件目录说明） |
